# YOLOv12 with Optuna

Hyperparameter optimization for YOLOv12 in camouflaged animal detection using Optuna framework with the MoCA dataset.

## Overview

This repository contains the implementation of my undergraduate thesis comparing baseline YOLOv12 performance against Optuna-optimized YOLOv12 for detecting camouflaged animals. The project leverages the [MoCA (Moving Camouflaged Animal)](https://www.robots.ox.ac.uk/~vgg/data/MoCA/) dataset to evaluate improvements in detection performance through systematic hyperparameter tuning.

## Objectives

This research aims to:
1.    Analyse the effect of hyperparameter optimisation using the Optuna framework on improving the performance of YOLOv12 in detecting camouflaged animals in the MoCA dataset.
2.    Identify the optimal hyperparameter combination generated by Optuna for the YOLOv12 configuration in the context of camouflaged animal detection.
3.    Compare the performance of the optimised YOLOv12 model with the baseline model without optimisation to evaluate the effectiveness of the hyperparameter optimisation method. 

## Dataset

**[MoCA](https://www.robots.ox.ac.uk/~vgg/data/MoCA/) Dataset** - A specialized dataset for camouflaged object detection
- Focus: Camouflaged animals in natural environments
- Challenge: Objects with high visual similarity to their backgrounds

| **Precision** | 0.9969 (99.69%) | 1.0000 (100%) | **+0.31%** |
| **Recall** | 1.0000 (100%) | 1.0000 (100%) | +0% |
| **F1-Score** | 0.9984 (99.84%) | 1.0000 (100%) | **+0.16%** |
